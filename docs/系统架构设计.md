# 系统架构设计

> [← 文档目录](README.md) · [← 返回 README](../README.md)

单体 Spring Boot 项目，前后端分离，接口前缀 `/api`，端口 `8080`。

![系统架构图](images/architecture.png)

---

## 一句话说明

管理端 / 门店端前端 → Spring Boot 后端 → PostgreSQL 存业务数据、Redis 存登录态和权限缓存、本地磁盘存图片。

---

## 技术栈

| 类别 | 选用 |
|------|------|
| 语言 / 框架 | Java 17 · Spring Boot 3.2.5 |
| 安全 | Spring Security · JWT 双 Token |
| 数据库 | PostgreSQL 14+ |
| 缓存 | Redis 7+ |
| ORM | MyBatis-Plus 3.5.5 |
| 文档 | Knife4j（`/api/doc.html`） |

---

## 代码怎么分层

```
com.inventory/
├── common/       公共工具、统一响应 Result
├── config/       Spring 配置（Security、Redis、MyBatis…）
├── framework/    横切能力（JWT、权限、日志、限流、异常）
└── modules/      业务模块（auth / goods / order / shop…）
```

请求大致路径：**JWT 鉴权 → Controller → Service → Mapper → 数据库**

---

## 横切能力（右侧图里那些）

| 能力 | 干什么 |
|------|--------|
| 权限控制 | RBAC 校验，没权限直接拦 |
| 操作日志 | 记录谁改了什么 |
| 接口限流 | 防刷，如注册接口 |
| API 监控 | 统计接口耗时 |
| 全局异常 | 统一返回 JSON 错误 |
