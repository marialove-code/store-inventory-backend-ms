## 二、图 A — 面向对象（OOP 生活版）

### 2.1 三大特征（中心）

| 特征 | 生活例子 | 项目挂钩 |
|------|----------|----------|
| **封装** | 银行卡余额 private，用存/取方法 | Controller→Service 分层 |
| **继承** | 学生/老师都是人 | 子类 extends 父类 |
| **多态** | 编译看左、运行看右 | `OrderCreateConcurrencyStrategy` + V1/V2 实现 |

### 2.2 其他要点（图内章节）

- **类 vs 对象**：图纸 vs 造出来的实例（`new`）
- **抽象类 / 接口**：是什么 vs 能做什么；Spring 里 Service 接口 + Impl
- **static**：全类一份（全校名）；**实例字段**：每个对象一份
- **final**：引用不可改；final 类不可继承
- **Object**：万物之父；默认 `equals` = `==`；`String` 重写 equals 比字符

### 2.3 口播 20 秒

> OOP 核心是封装隐藏细节、继承复用、多态同一引用不同行为。项目里策略接口 + 多实现就是多态。

## 三、图 B — 变量与对象创建

### 3.1 五种写法对照表

| 代码 | 栈 | 堆 | 说明 |
|------|----|----|------|
| `int a = 100` | 值 `100` | 无 | 基本类型，不进堆 |
| `Integer a = 100` | 引用 | Integer 对象 | 自动装箱；127 内可能缓存 |
| `Person p = new Person()` | 引用 | Person 对象 | 类信息在元空间 |
| `String s = "hi"` | 引用 | **字符串常量池**（在堆里） | 同字面量复用 |
| `String s = new String("hi")` | 引用 | **新** String 对象 | 与 `"hi"` 字面量可能不是同一对象 |

### 3.2 `new` 对象时 JVM 五步

1. **类加载检查**（未加载则 ClassLoader 加载 → 元空间）
2. **堆上分配内存**
3. **字段赋默认值**（0 / null）
4. **执行构造方法 `<init>`**
5. **栈里变量保存引用**（箭头指向堆）

### 3.3 重要修正（与图 B 底部 Tips 对齐）

| 说法 | Java 8+ 正确理解 |
|------|------------------|
| 字符串常量池在方法区 | ❌ **Java 7 起在 Java 堆** |
| 方法区 | ✅ 实现为 **元空间 Metaspace**，**不在 `-Xmx` 堆里** |
| static | ✅ 跟着 **类**，在元空间（类元数据） |

### 3.4 面试常考点（图 B 右下角）

- `String s1 = "a"; String s2 = new String("a");` → **`s1 == s2` 为 false**
- `Integer i1=127; Integer i2=127;` → **`==` 可能 true**（-128～127 缓存）
- `new String("a")` → 可能 **1～2 个对象**（池里是否已有 `"a"`）

## 四、图 C — JVM 内存结构总览

### 4.1 五块区域 + 生活比喻

| 区域 | 共享/私有 | 放什么 | 比喻 |
|------|-----------|--------|------|
| **方法区**（元空间） | 共享 | 类信息、static、类运行时常量池、JIT 代码 | 图纸库 |
| **堆** | 共享 | 对象、数组、**字符串常量池** | 仓库 |
| **Java 栈** | 每线程私有 | 栈帧：局部变量、引用、操作数栈 | 服务员记事本 |
| **本地方法栈** | 每线程私有 | native 方法（如 `Thread.sleep`） | 外包团队 |
| **程序计数器** | 每线程私有 | 当前执行的字节码位置 | 书签 |

**栈指针 SP**：手指指向 **当前栈顶** 栈帧；方法调用 **压栈**，返回 **弹栈**（LIFO）。

### 4.2 栈帧里有什么（图 C 栈区详图）

- 局部变量表（`age`、`p` 引用等）
- 操作数栈
- 动态链接、方法返回地址  

**Python Tutor 里的 `Frames: main`** = **main 方法的栈帧**。

### 4.3 执行过程示例（main 调 sayHi）

1. 类加载进 **元空间**
2. `new Person()` 在 **堆**
3. `main` / `sayHi` 各压一层 **栈帧**
4. 局部变量 `p` 在栈，**引用** 指向堆对象
5. **PC** 逐条执行字节码

### 4.4 Java 7 vs 8+（版本对照）

| 内容 | Java 7 及以前 | Java 8+ |
|------|---------------|---------|
| 方法区实现 | PermGen（在堆内） | Metaspace（堆外） |
| 字符串常量池 | 堆 | 堆 |
| `-Xmx` | 管堆（含 PermGen） | 只管堆，**不含**元空间 |

### 4.5 直接内存（图 C 可未画）

- NIO / Netty 用的 **堆外内存**，不受 `-Xmx` 限制，但占进程总内存
- 模块 4/5「知道名字即可」

## 五、`==` 与 `equals`（已掌握，复习锚点）

### 5.1 规则

| | `==` | `equals` |
|---|------|----------|
| 基本类型 | 比数值 | 无 |
| 引用类型 | 比 **是否同一对象** | 默认 = `==`；重写后比 **业务字段/内容** |

### 5.2 String.equals 结构（源码级）

```java
// Object 默认
return (this == obj);

// String：先 == 同对象则 true；否则逐字符比 value[]
```

### 5.3 四套对比（建议能口述）

| 代码 | `==` | `equals` |
|------|------|----------|
| `c/d` 字面量 `"hi"` | true（同一对象） | true（第一行 == 即 true） |
| `a/b` 两个 `new String("hi")` | false | true（比字符） |

### 5.4 面试 30 秒

> 基本类型 `==` 比值；引用类型 `==` 比地址。`Object.equals` 默认等同 `==`；需要按业务相等时重写 equals，String 重写后比字符。用作 HashMap key 时还要重写 hashCode——**见模块 3 集合**。

## 六、三图一致性检查清单

复习时对照，**全部打勾即 JVM+引用基础过关**：

- [ ] 基本类型在栈存值，不建堆对象
- [ ] 引用类型：栈存箭头，堆存对象
- [ ] 字面量 `"hi"` 在 **堆** 的字符串常量池，可复用
- [ ] `new String("hi")` 堆上 **新对象**，`==` 与字面量常为 false
- [ ] 方法区 Java 8+ = 元空间，**不在 Java 堆**
- [ ] static 跟着类；实例字段在堆对象里
- [ ] 每个线程：独立 Java 栈 + PC + 本地方法栈
- [ ] 多线程 **共享堆** → 并发竞态在共享数据/DB
- [ ] `-Xmx` 只限制 **堆** 大小

## 九、口述模板（JVM + OOP + 并发，1 分钟）

> JVM 有方法区（Java 8 元空间存类与 static）、堆存对象和字符串常量池、每线程有 Java 栈存栈帧和引用、还有 PC 和本地方法栈。  
> `new` 在堆建对象，引用在栈；`==` 比地址，equals 按类定义比相等，String 比字符。  
> 多线程共享堆，我们 V1 无锁超锁，V2 ReentrantLock 按商品互斥，根因在 DB 竞态。
