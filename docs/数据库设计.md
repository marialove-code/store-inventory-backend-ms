# 数据库设计

> [← 返回 README](../README.md)

**PostgreSQL** · 库名 `inventory_store` · 主键雪花 ID · 重要表支持逻辑删除

---

## 表分组（共 20 张）

| 分组 | 表 | 说明 |
|------|-----|------|
| **权限** | `sys_user` `sys_role` `sys_permission` `sys_user_role` `sys_role_permission` | 用户、角色、权限 |
| **日志** | `sys_login_log` `sys_operation_log` | 登录、操作记录 |
| **监控** | `sys_api_monitor` | 接口耗时统计 |
| **商品** | `goods_brand` `goods_category` `goods_product` | 品牌、分类、商品 |
| **库存** | `inventory_stock` `inventory_in` `inventory_out` `inventory_flow` | 库存、入出库单、流水 |
| **订单** | `order_info` `order_delivery` `order_refund` | 订单、发货、退款 |
| **门店** | `shop_product` `shop_sale_record` | 门店商品、销售流水 |

---

## 关系简图

```
用户 ──角色── 权限（RBAC 五表）

品牌、分类 ──→ 商品 ──→ 库存 ──→ 入出库 / 流水

订单 ──→ 发货 / 退款（和库存锁定、扣减联动）

门店商品 ──→ 销售流水（独立记账线）
```

详细 ER 与字段见下方核心表说明；联调以代码实体和 Knife4j 为准。

## 核心表字段（精简）

### RBAC

**sys_user** — 账号、BCrypt 密码、昵称、手机、状态  
**sys_role** — 角色名、`role_code`（如 `SUPER_ADMIN`）  
**sys_permission** — 权限名、`perm_code`、`perm_type`（M/C/F）、`parent_id` 树形

### 商品 & 库存

**goods_product** — 名称、分类、品牌、售价、成本、上下架  
**inventory_stock** — 商品 ID、库存数、锁定数、预警值、状态（正常/预警/缺货）  
**inventory_flow** — 变动类型（入/出/锁/解锁）、变动前后数量、关联单号

### 订单

**order_info** — 订单号、状态（0~6）、金额、商品信息  
**order_delivery** — 发货状态、物流单号  
**order_refund** — 退款状态、审核结果

### 门店

**shop_product** — 门店配件、库存、售价、成本、厂家、厂家联系方式、备注  
**shop_sale_record** — 商品、数量、成交价、总额、**利润**、销售时间

---

## 库存状态规则

| 条件 | 状态 |
|------|------|
| 库存 = 0 | 缺货 |
| 0 < 库存 ≤ 预警值 | 预警 |
| 库存 > 预警值 | 正常 |
