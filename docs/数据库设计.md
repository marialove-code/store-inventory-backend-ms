# 数据库设计

> 数据库：PostgreSQL 14+  
> 数据库名：`inventory_store`  
> ORM：MyBatis-Plus 3.5.5  
> 主键策略：雪花算法（`IdType.ASSIGN_ID`）  
> 逻辑删除：字段 `deleted` / `isDeleted`，0=未删除，1=已删除

## 10. 设计规范

| 规范 | 说明 |
|------|------|
| 命名 | 表名小写 + 下划线，字段小写 + 下划线 |
| 主键 | 统一 BIGINT 雪花 ID |
| 时间 | `create_time` + `update_time`，自动填充 |
| 逻辑删除 | RBAC/商品表使用 `is_deleted` 或 `deleted` |
| 冗余字段 | 订单/库存表冗余 `goods_name` 等，避免联表 |
| 金额 | `DECIMAL(10,2)` 存储价格 |
| 状态 | INT 枚举，业务层用 Enum 类管理 |
