## 2. 第 0 档 — 智搜 V2（当前执行）

### 2.1 要做什么

> 用户口语（不一定含精确商品名）→ **Embedding 向量** → TopK 语义相近商品/文案 →（可选）塞进 Prompt 让 LLM 总结。

和已有能力分工：

| | 智搜 V1（已有） | ES（已有） | 智搜 V2（本档） |
|--|-----------------|-----------|-----------------|
| 核心 | LLM → 筛选 JSON | 倒排关键词 | 向量语义 |
| 例子 | 「一千以内小米」 | 搜「小米」 | 「续航久的手表」 |

### 2.2 最小闭环（做完标准）

- [x] 概念：Embedding、相似度、切块、RAG 四步  
- [x] 建库：商品名/规格等 → 向量存储（pgvector）  
- [x] 在线：一句话语义查询接口（旁路 + **商品页业务入口**）  
- [x] RAG 生成：TopK + LLM 推荐理由（`withRag=true`，insight 展示） 
- [x] 笔记：写入智搜笔记 / AI 手册  
- [x] 口述 40 秒：V1 / ES / V2 三分法；**不锁库存**

### 2.3 本档明确不做

- 生产向量集群、完整评测平台  
- 前端主列表大改（旁路接口够）  
- 与并发锁库存混叙事  

### 2.4 建议耗时

约 **3～5 天**（含概念 + 最小代码 + 笔记）；可按卡住点延长，但先保「能演示」。

## 4. 第 2 档 — 8/1 之后：循序渐进（3 小步）

每步大约 **3～7 天**（面试密集时可拉长到两周一步）。

### Step A — Tool / Function Calling【优先】

- [ ] 概念：模型决定何时调业务 API  
- [ ] 最小做：客服或助手能调 **1～2 个**已有接口（如查库存快照）  
- [ ] 口述：「AI 调工具，真相仍在服务 / 数据库」

### Step B — 极简 Agent【可选】

- [ ] 多步：理解 → 调工具 → 汇总（限制 2～3 步）  
- [ ] **不做** 复杂自主 Agent 平台、重型编排框架（除非 JD 点名）

### Step C — 护栏与体验【持续小补】

- [ ] 回答带「依据」（哪条商品/文档）  
- [ ] 记录约 5 条 bad case  
- [ ] 关注超时 / 空检索 / 非法 JSON 日志
