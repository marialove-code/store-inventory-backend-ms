### 事务风险（本阶段接受）

本地 `@Transactional` **管不到** 远程库存 HTTP。建单采用「先 lock 再 save + save 失败尝试 unlock」；发货/退款仍存在「库存已变、本地未提交」窗口，后续用补偿/对账收敛。
