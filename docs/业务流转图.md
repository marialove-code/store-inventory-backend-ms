## 一、商品管理

维护**品牌、分类、商品**基础信息。

- 新增商品时可设**初始库存**和**预警值**
- 编辑商品改名称、价格、图片等；**库存数量在库存模块改**，不在商品编辑里改

---

## 二、库存管理

| 操作 | 结果 |
|------|------|
| 入库 | 库存 +N，写一条流水 |
| 出库 | 库存 -N，写一条流水 |
| 下单 | 锁定库存（防超卖） |
| 取消 / 退款 | 解锁或回库，写流水 |

**可用库存 = 实际库存 − 锁定库存**

库存流水只读，记录每次变动，方便对账。

---

## 三、订单管理

```
待支付 → 待发货 → 已发货 → 已收货
   ↓        ↓
 已取消   退款中 → 退款完成 / 拒绝还原
```

| 节点 | 库存变化 |
|------|----------|
| 创建订单 | 锁定库存 |
| 确认发货 | 扣减真实库存，写出库 |
| 取消订单 | 释放锁定 |
| 退款通过 | 退货入库 |

---

## 四、门店开单（项目初心）

独立于上面订单体系，走 `/shop/*`：

**选商品 → 开单 → 扣门店库存 → 记流水（金额 + 利润） → 看板统计**

---

## 五、整体关系

```
商品（主数据）→ 库存（数量）→ 订单（驱动锁定/扣减）→ 流水（全程记录）
```

门店模块是轻量记账线，和管理端进销存共用后端、数据分开表存。
