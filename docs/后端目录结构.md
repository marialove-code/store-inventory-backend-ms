# 后端目录结构

> [← 文档目录](README.md) · [← 返回 README](../README.md)

---

## 项目根目录

```
store-inventory-backend/
├── docs/                 文档
├── src/main/java/        Java 源码
├── src/main/resources/   配置 + MyBatis XML
├── pom.xml
└── README.md
```

---

## 源码四层

```
com.inventory/
├── InventoryApplication.java    启动类
├── common/                      统一响应、工具类、常量
├── config/                      Spring 配置
├── framework/                   JWT、权限、日志、限流、异常
└── modules/                     业务代码（按领域分包）
```

---

## 业务模块 `modules/`

| 包 | 干什么 |
|----|--------|
| `auth` | 登录、注册、Token |
| `system` | 用户、角色、权限、日志 |
| `goods` | 品牌、分类、商品 |
| `invertory` | 库存、入出库、预警、流水 |
| `order` | 订单、发货、退款 |
| `shop` | 门店开单、销售流水、门店看板 |
| `dashboard` | 管理端首页看板 |
| `monitor` | API / 服务器 / Redis 监控 |
| `own` | 个人中心 |

> 包名 `invertory` 是历史拼写，路由前缀仍是 `/inventory`。

---

## 单个模块里一般有什么

```
controller/    接 HTTP 请求
service/       业务逻辑
mapper/        查数据库
entity/        表对应实体
dto/           入参
vo/            出参
```

---

## 配置文件

| 文件 | 用途 |
|------|------|
| `application.yml` | 主配置，选 dev / prd 环境 |
| `application-dev.yml` | 本地开发（库、Redis、跨域） |
| `application-prd.yml` | 生产环境 |
| `mapper/**/*.xml` | 复杂 SQL |
