# 后端目录结构

> 项目：`store-inventory-backend`  
> 技术栈：Spring Boot 3.2.5 · JDK 17 · MyBatis-Plus · PostgreSQL · Redis  
> 接口前缀：`/api`（`application-dev.yml` → `server.servlet.context-path`）  
> 构建产物：`store-inventory-backend.jar`

---

## 业务模块标准分包

每个业务子模块遵循统一分层：

```
modules/{domain}/{submodule}/
├── controller/        # 控制层：接收请求、权限注解、参数校验
├── service/           # 业务接口
│   └── impl/          # 业务实现
├── mapper/            # MyBatis Mapper 接口
├── entity/            # 数据库实体
├── dto/               # 入参对象（Request）
├── vo/                # 出参对象（Response）
└── convert/           # 对象转换（部分模块有）
```

## 分层职责说明

| 层级 | 包路径 | 职责 |
|------|--------|------|
| 公共层 | `common` | 响应体、异常、工具、常量，不含业务逻辑 |
| 配置层 | `config` | Spring Bean 配置、第三方组件集成 |
| 基础设施层 | `framework` | 日志、鉴权、限流、全局异常等横切能力 |
| 业务层 | `modules` | 领域业务，Controller → Service → Mapper |
| 持久层 | `resources/mapper` | 复杂 SQL 的 XML 映射 |

## 命名约定

| 类型 | 规范 | 示例 |
|------|------|------|
| Controller | `XxxController` + `@RequestMapping` | `SysRoleController` |
| 权限注解 | `@RequiresPerm("模块:资源:操作")` | `system:user:list` |
| 操作审计 | `@OperationLog` | 增删改自动记录 |
| 接口限流 | `@RateLimit` | 注册接口防刷 |
| 统一返回 | `Result<T>` | `{ code, message, data }` |
| 主键策略 | 雪花算法 `IdType.ASSIGN_ID` | 分布式唯一 ID |
| 逻辑删除 | `@TableLogic` 字段 `deleted` / `isDeleted` | 软删除 |
