# 后端功能模块

> [← 文档目录](README.md) · [← 返回 README](../README.md)

接口前缀：`/api` · 鉴权：`Authorization: Bearer {token}` · 在线文档：`/api/doc.html`

---

## 模块一览

| 模块 | 路由前缀 | 做什么 |
|------|----------|--------|
| 认证 | `/auth` | 注册、登录、登出、刷新 Token |
| 看板 | `/dashboard` | 管理端首页统计 |
| 系统 | `/sysUser` `/sysRole` `/sysPermission` | 用户、角色、权限、菜单 |
| 日志 | `/system/login/log` `/system/operate/log` | 登录日志、操作日志 |
| 商品 | `/goods/*` | 品牌、分类、商品 CRUD |
| 库存 | `/inventory/*` | 库存列表、入出库、预警、流水 |
| 订单 | `/order/*` | 订单、发货、退款 |
| 门店 | `/shop/*` | 开单、流水、门店看板 |
| 监控 | `/monitor/*` | API、服务器、Redis |
| 个人 | `/profile` | 个人中心、我的日志 |

---

## 门店模块（项目起点）

| 能力 | 说明 |
|------|------|
| 开单 | `POST /shop/sale`，扣库存、记金额和利润 |
| 流水 | `GET /shop/record/list` |
| 统计 | `GET /shop/sale/stats`，今日 / 本月营收 |
| 看板 | `GET /shop/dashboard/overview` |

门店接口**登录即可用**，未接 RBAC 权限码。

---

## 商品 & 库存

- **商品**：品牌、树形分类、上下架、图片上传
- **库存**：入库 / 出库自动改库存并写流水；支持预警、锁定（给订单用）

---

## 订单

状态：待支付 → 待发货 → 已发货 → 已收货，可取消、可退款。  
下单锁库存，发货扣库存，取消 / 退款释放或回库。

---

## 系统 & 权限

- 用户 / 角色 / 权限树，按钮级控制
- 在线用户、强制下线
- 操作日志自动记录（`@OperationLog`）

详见 [RBAC 权限设计](RBAC权限设计.md)
