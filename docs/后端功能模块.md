# 后端功能模块

> 接口基础路径：`http://{host}:8080/api`  
> 鉴权方式：`Authorization: Bearer {accessToken}`  
> 权限控制：`@RequiresPerm` + AOP 切面（超级管理员 `SUPER_ADMIN` 放行）  
> 接口文档：http://localhost:8080/api/doc.html

## 1. 认证中心 `auth`

| 能力 | 说明 |
|------|------|
| 用户注册 | 用户名唯一校验，BCrypt 加密，自动绑定普通用户角色 |
| 用户登录 | 校验账号密码，签发双 Token，写入 Redis 登录态 |
| 用户登出 | 清除 Redis 中 AccessToken / RefreshToken |
| Token 刷新 | RefreshToken 换取新 AccessToken |
| 当前用户 | 返回用户基本信息、角色、权限码列表 |

**核心依赖**：`JwtUtil`、`UserSessionService`、`SysLoginLogService`（登录审计）

## 3. 系统管理 `system`

### 3.1 用户管理

- 用户分页查询、详情回显、编辑
- 启用/禁用、重置密码、逻辑删除
- 用户角色分配（多对多）
- 头像上传

### 3.2 角色管理

- 角色 CRUD、批量删除、状态切换
- 角色权限分配（勾选权限树）
- 下拉列表（`listAll`）供用户分配使用

### 3.3 权限管理

- 权限树维护（目录 M / 菜单 C / 按钮 F）
- 权限码 `perm_code` 与接口 `@RequiresPerm` 一一对应
- 超管可获取全部权限码列表

### 3.4 菜单管理

- 当前用户侧边栏菜单树（`GET /system/menu/all`）
- 菜单 CRUD（管理端配置）

### 3.5 在线用户

- 查看 Redis 中活跃会话
- 强制下线（删除 Token）
- Redis Key 浏览与删除

### 3.6 日志管理

- **登录日志**：分页、导出 Excel、清空
- **操作日志**：分页、导出 Excel（`@OperationLog` 自动采集）

## 5. 库存管理 `invertory`

> 包名拼写为 `invertory`，路由前缀为 `/inventory`

| 子模块 | 能力 |
|--------|------|
| 库存列表 | 实时库存查询、预警阈值修改 |
| 入库管理 | 新增入库单 → 自动增加库存 + 写流水 |
| 出库管理 | 新增出库单 → 自动扣减库存 + 写流水 |
| 库存预警 | 预警/缺货商品列表、阈值调整 |
| 库存流水 | 全量变动记录查询、Excel 导出 |

**库存联动规则**：

- 入库/出库操作通过 `StockService` 统一处理
- 每次变动自动写入 `inventory_flow` 流水表
- 自动刷新库存状态：1=正常、2=预警、3=缺货
- 支持锁定库存（订单预占）与解锁

## 6. 订单管理 `order`

### 6.1 订单列表

| 状态码 | 状态 | 说明 |
|--------|------|------|
| 0 | 待支付 | 创建订单，锁定库存 |
| 1 | 待发货 | 支付成功，生成发货单 |
| 2 | 已发货 | 确认发货，扣减真实库存 |
| 3 | 已收货 | 用户确认收货 |
| 4 | 退款中 | 发起退款申请 |
| 5 | 退款完成 | 审核通过，库存回库 |
| 6 | 已取消 | 释放锁定库存 |

### 6.2 发货管理

- 待发货订单列表
- 确认发货（填写物流单号）→ 扣减库存 → 同步主订单状态

### 6.3 退款管理

- 退款申请（已支付/已发货/已收货可申请）
- 审核通过 → 退货入库
- 审核拒绝 → 恢复原订单状态

## 11. 权限码与前端菜单对应

```
系统管理  →  system:*
商品管理  →  goods:*
库存管理  →  inventory:*
订单管理  →  order:*
系统监控  →  monitor:*
```

权限类型（`sys_permission.perm_type`）：

- **M**：目录（侧边栏一级）
- **C**：菜单（侧边栏二级页面）
- **F**：按钮（页面内操作，不渲染到菜单）

前端通过 `GET /system/menu/all` 获取 M + C 树；按钮权限由用户 `perm_code` 列表控制显隐。
