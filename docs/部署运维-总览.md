## 1. 线上拓扑（当前）

```text
浏览器 → Nginx:443（nestparts.top）
         ├─ 静态前端 → /www/wwwroot/inventory-ms-front
         ├─ /api/*    → 127.0.0.1:9080（Gateway）
         └─ /upload/* → 静态目录或经 Gateway → platform

Gateway → Nacos 发现 → platform:8081 / inventory:8082 / order:8083 / ai:8084
PostgreSQL / Redis / Nacos：宿主机
order：已可用 Docker 容器 order-c（--network host + prd）
```

---

## 2. 端口规划（2 核 4G）

| 进程 | 端口 | 公网 |
|------|------|------|
| Nginx | 80/443 | 开 |
| Gateway | **9080** | 仅本机（经 Nginx） |
| platform / inventory / order / ai | 8081～8084 | 仅本机 |
| Nacos | 8848 | 建议仅本机 |
| PostgreSQL / Redis | 5432 / 6379 | 勿对公网 |
| 业务 JVM | 建议 `-Xms128m -Xmx256m` | — |

脚本：`scripts/start-all.sh` / `stop-all.sh`；环境变量：`/opt/inventory-ms/env.sh`（勿进 Git）。

---

## 3. 域名切流要点

1. 前端 `npm run build` → 上传 `dist/` 到 `inventory-ms-front`  
2. 宝塔站点 root 指前端目录  
3. Nginx：`/api`、`/upload` 反代或 alias（样例见 [域名切换-Nginx-微服务.md](./域名切换-Nginx-微服务.md) 与 `docs/nginx/`）  
4. 前端生产 `VITE_API_BASE_URL=/api`（同源）
